## Project 001 - Counter App

# Counter App

Simple counter with increment and decrement.

## Features

✅ Display counter value
✅ Increment button
✅ Decrement button
✅ Reset button
✅ Real-time updates
✅ Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Gradients)
- Vanilla JavaScript (ES6+)
