# Digital Clock

Real-time clock display.

## Features

✅ Current time display
✅ HH:MM:SS format
✅ Real-time updates
✅ AM/PM indicator
✅ Large readable text
✅ Responsive sizing

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Typography)
- Vanilla JavaScript (ES6+)
