## Project 012 - Temperature Converter

# Temperature Converter

Convert Celsius to Fahrenheit.

## Features

✅ Celsius input
✅ Fahrenheit input
✅ Bidirectional conversion
✅ Real-time update
✅ Kelvin display
✅ Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid)
- Vanilla JavaScript (ES6+)
