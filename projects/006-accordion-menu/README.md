## Project 006 - Accordion Menu

# Accordion Menu

Expandable accordion sections.

## Features

✅ Click to expand
✅ Click to collapse
✅ Arrow rotation
✅ Smooth animation
✅ Multiple/single open
✅ Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Gradients)
- Vanilla JavaScript (ES6+)

## Live Demo
